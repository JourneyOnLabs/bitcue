# Getting help

- **Something doesn't work** (the screen, a tool change, the installer, notifications): open an issue with
  the "Something doesn't work" template. Include what `http://z1screen.local:8080/debug` shows.
- **Which parts to buy, the housing's fit, or putting it together:** open an issue with the "Hardware
  question" template. The parts list is in [Get the hardware](docs/buy.md).
- **An order:** the 3D files are handled through the store you bought them from (Printables Store or
  Cults3D). See
  [Help with an order](docs/buy.md#help-with-an-order).
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md) says.

BitCue is a one-person project, so answers can take a few days. It is not made or supported by Makera:
for problems with the Z1 itself, contact Makera.
