      Add a cut area by hand

      For a job the Pi didn't see. Pick its file and its offsets from Anchor 1, or type a rectangle.

      Bits and sticker colors

      At each stop, the screen turns the color of the bit number (T1, T2 ...). Use each number for one bit only.

        Bit life

        The time each bit has cut, by the Z1's own job clock (stops and pauses not counted). Bits of the same kind are labelled A, B, C: mark the holder the same way. At each stop the screen names the least used one; tap its line there to use another.

        Expected life: leave it blank until a few bits have worn out. Set it and the gauge under the bit's line on the stop screen fills green, then yellow, then red as the bit wears, the start screen warns before a job that would take a bit past it, and so does your phone.

        Demo on the Pi's screen

        Plays a job on the Pi's screen while the Z1 is idle. Nothing is sent to the Z1.
